# Fe_Yb
# Fe/Yb - Magnetismo interfacial inducido por deformación

## Objetivo

Estudiar mediante VASP el origen microscópico de la anisotropía
magnética anómala y del intercambio entre clusters de Fe embebidos
en una matriz de Yb.

Hipótesis principal:

strain
→ reconstrucción/hibridación Fe-Yb
→ polarización interfacial
→ SOC / MAE / intercambio
→ propiedades magnéticas macroscópicas

## Métodos principales

- VASP
- DFT / DFT+U
- SOC
- MAE
- Bader
- Wannier90
- TB2J
- MACE
- Vampire / Monte Carlo
